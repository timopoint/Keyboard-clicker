# Keyboard Clicker
Простой автокликер текста с графическим интерфейсом на Python. 

Программа автоматически вводит заданный текст с определенным интервалом времени при нажатии на горячую клавишу. 

Настройки сохраняются в файл конфигурации.

## Функционал

Автоматический ввод: Печатает заданный текст бесконечным циклом в фоновом потоке.

Смена горячей клавиши: Позволяет назначить любую клавишу для запуска и остановки кликера.

Настройка задержки: Возможность указать интервал между повторениями ввода в секундах.

Сохранение настроек: Автоматически создает файл Options.json и сохраняет параметры при закрытии приложения.

## Требования 

Для работы программы необходим Python версии 3.x и следующие библиотеки:

tkinter (обычно идет в комплекте с Python)

keyboard (для отслеживания и эмуляции нажатий клавиш)

## Как использовать
Изменение горячей клавиши: Нажмите кнопку change hotkey, после чего сразу нажмите нужную клавишу на клавиатуре.

Установка текста: Введите нужную фразу в поле Enter text: и нажмите кнопку set text.

Установка задержки: Укажите время в секундах в поле Delay in seconds: и нажмите set delay.

Запуск/Остановка: Нажмите назначенную горячую клавишу (по умолчанию F1), чтобы включить автопечать. 

Повторное нажатие остановит процесс.

Закрытие: При закрытии окна программы все текущие настройки запишутся в файл Options.json
